# The Complaint That Was Never Filed

An AI-driven complaint management and risk prediction system designed to address the **blind spot of unreported safety incidents**. This project digitizes complaint handling, leverages fragmented data signals, and uses machine learning to uncover hidden risks in public spaces.

---

## 📌 Problem Statement

Many safety incidents go **unreported** due to fear, confusion, or lack of proof.  
This causes a **data gap**, making it hard to see real risks.​
Some clues exist but as **incomplete data**.

Our challenge: **design an AI-based system** that can estimate and predict underreported incidents using indirect and incomplete data, while ensuring privacy and ethical analysis.

---

## 🚀 Project Overview

**The Complaint That Was Never Filed** is a web-based platform that enables:  
- Digital complaint submission and tracking  
- Location-based tagging of incidents  
- AI-powered risk estimation from fragmented data sources  
- Transparent communication between users and authorities  

The system bridges the gap between **citizens and policymakers**, ensuring proactive interventions even when formal complaints are missing.

---

## ✨ Features

- 📝 Easy complaint submission with structured forms  
- 📍 Location-based tagging for contextual insights  
- 📊 Complaint status tracking (Pending / In Progress / Resolved)

- 👥 User-friendly interface accessible to all
